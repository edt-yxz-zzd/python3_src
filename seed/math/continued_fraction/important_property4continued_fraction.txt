6.7.3 Wiener’s Low Decryption Exponent Attack
Algorithm 6.11: WIENER’S ALGORITHM(n,b)
  RSA:漏洞之一:私钥太小
  变量含义:
  [n :: 模]
  [b :: 公钥]
  [a :: 私钥]

  [p,q::prime]
  [n == p*q]
  [phi_(n) == (p-1)*(q-1)]
  [2 <= a < phi_(n)]
  [2 <= b < phi_(n)]
  [a*b %phi_(n) == 1]
  [t := (a*b-1)///phi_(n)]
  [a*b == 1+t*phi_(n)]
  [1 == gcd(a,t)]
  !! [2 <= b < phi_(n)]
  [a == 1/b +t*phi_(n)/b > t]

  !! [4 <= a*b]
  [t > 0]
  [0 < t < a]

  漏洞前提:
  [3*a < n**/4][q < p < 2*q]

  漏洞由来:
  !! [q < p]
  [n == p*q > q**2]
  [q < n**/2]
  !! [p < 2*q]
  [0 < n -phi_(n) == p+q-1 < 2*q+q-1 < 3*q < 3*n**/2]
  [1 <= n -phi_(n) < 3*n**/2]
  [t <= t*(n -phi_(n)) < t*3*n**/2]
  !! [t > 0]
  [0 <= t-1 <= t*(n -phi_(n))-1 < t*3*n**/2]
  [abs(b/n - t/a)
  == abs((a*b-t*n)/(a*n))
  !! [a*b == 1+t*phi_(n)]
  == abs(((1+t*phi_(n))-t*n)/(a*n))
  == abs((1-t*(n-phi_(n)))/(a*n))
  !! [0 <= t-1 <= t*(n -phi_(n))-1 < t*3*n**/2]
  < (t*(3*n**/2))/(a*n)
  == (3*t)/(a*(n**/2))
  !! [0 < t < a]
  < 3/(n**/2)
  !! [3*a < n**/4]
  => [9*a**2 < n**/2]
  < 3/(9*a**2)
  == 1/(3*a**2)
  < 1/(2*a**2)
  ]
  [abs(b/n - t/a) < 1/(2*a**2)]

  !! [[abs(a/b - c/d) < 1/(2*d**2)] -> [(c/d) is one of the convergents of the continued fraction expansion of (a/b)]]
  [(t/a) is one of the convergents of the continued fraction expansion of (b/n)]
      # NOTE: [1 == gcd(a,t)]
